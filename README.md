# 回家自动化 APK

一个用于Android设备的自动化应用，回家后自动打开电脑和显示器挂灯。

## 功能

- ✅ WiFi连接时自动触发
- ✅ 快捷打开UU远程和米家应用
- ✅ 自动化测试功能
- ✅ 状态通知

## 构建

使用 GitHub Actions 自动构建APK：
1. 推送代码到GitHub
2. Actions自动构建
3. 下载构建好的APK

## 使用方法

1. 安装APK到Android设备
2. 打开应用，授予必要权限（位置、WiFi等）
3. 输入家庭WiFi名称
4. 点击"启动自动化"

## 配置

- **WiFi名称**: 连接此WiFi时自动触发
- **纬度/经度**: 位置触发（可选）

## 快捷操作

- UU远程: 一键打开UU远程应用
- 米家: 一键打开米家应用

## 注意事项

需要预先安装以下应用：
- UU远程 (com.bbk.uu)
- 米家 (com.xiaomi.smarthome)
